#BackendEngineering 

# Introduction
- Latency - How long one request takes
- Throughput - how many requests a system can handle per unit of time

Throughput is not equivalent to latency because we can process many requests at the same time in the system. For example, processing one request takes 5 sec and our system can process 10 requests at the same time, so throughput is 120 requests per minute.
