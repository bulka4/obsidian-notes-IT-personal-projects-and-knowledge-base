# Introduction
- **Logs** - A collection of sentences (text) which informs us about what events happened.
- **Metrics** - Calculated numbers representing system performance. For example average latency, throughput, CPU usage (max, min, average).
- **Traces** - Traces are used when a single request is being passed through multiple functions within a single service or through multiple services in a distributed system. Traces tell us how much time each function / service took to process the request.
