#BackendEngineering 

# Introduction
RBAC is an authorization method where we decide whether an action is allowed or denied based on user's role.

So we assign permissions to roles and roles to users. User has permissions specified by the assigned role.
# Benefits
- Simple to understand
- Easy to manage in organizations
# Drawbacks
- Roles can become messy and difficult to manage if we have too many roles
