# What techniques to use in projects
More important:
- Java and Spring
- Dealing with too many incoming requests - avoiding processing too many requests at once when they come, e.g. using thread pools, backpressure  
- concurrency - semaphores, locks, race conditions, deadlocks, async programming
- distributed systems - conflict resolution, reconciliation
- running multiple threads
- CQRS, backend for frontend, event sourcing, saga, 
- dependency management (e.g. dependency injection)
- monitoring and logging
- fault tolerance
- api design - streaming API
- data consistency

other recommended by ChatGPT:
- Java multithreading, executors, synchronization and thread safety.     
- Distributed workflows, partial failures, retries and reconciliation.    
- Backend scalability: rate limiting, backpressure, caching and resource management.

Less important:
- distributed systems - consensus, partial failures, clock synchronization and logical clocks
- api design - graphQL, api gateway
