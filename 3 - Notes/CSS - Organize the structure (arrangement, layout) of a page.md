# Introduction
To organize the structure (arrangement, layout) of a page, we can use options such as:
- Flexbox (`display: flex`) - Arranges elements in a row or column.
- CSS Grid (`display: grid`) - Arranges elements into rows and columns.
- Positioning (`position`) - Controls the position of elements relative to their normal position, their parent, or the viewport. Common values:
	- `static` – default positioning.
	- `relative` – positioned relative to its normal position.
	- `absolute` – positioned relative to a positioned ancestor.
	- `fixed` – positioned relative to the viewport.
	- `sticky` – switches between normal and fixed-like positioning when scrolling.
- CSS box model (margin, padding, border, width, height).
