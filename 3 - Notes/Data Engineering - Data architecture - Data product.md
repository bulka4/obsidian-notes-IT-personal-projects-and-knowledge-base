# Introduction
A data product is a data asset designed and managed as a product, meaning it has users, a purpose, ownership, quality expectations, documentation, and a lifecycle.

What do we call a product is important because it affects its ownership, documentation etc., for example:
- If we call 5 different services a single data product, it has one owner and documentation
- If we have 5 different services and call each one a separate data product, then each one has its own owner and documentation
