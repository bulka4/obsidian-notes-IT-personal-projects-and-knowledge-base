# Introduction
DOM (Document Object Model) is a tree of objects representing the document (web page) in the browser's memory. It is used by a browser to display UI.

DOM can be created in different ways:
- by parsing HTML by the browser
- React can create it using on React elements ([[React - Components and elements|link]])

JavaScript can interact with the DOM to change the page—for example, change text, add elements, or remove elements
