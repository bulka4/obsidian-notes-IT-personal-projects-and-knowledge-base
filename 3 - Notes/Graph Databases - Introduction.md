#Databases  

# Introduction
In a graph database, we have:
- Nodes - representing objects
- Edges - representing relations between objects

For example, we might have data like this:
```
(Alice)     <- Node (object)
   |
 FRIEND_OF  <- Edge (relation)
   |
(Bob)
   |
 WORKS_WITH
   |
(Company)
```
