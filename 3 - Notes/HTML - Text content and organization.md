#Frontend #HTML 

# Introduction
HTML elements used to organize text:
- `<h1>`–`<h6>` – heading
- `<p>` – paragraph, used for blocks of text
- `<span>` – inline text container
- `<strong>` – important text (typically bold)
- `<em>` – emphasized text (typically italic)
