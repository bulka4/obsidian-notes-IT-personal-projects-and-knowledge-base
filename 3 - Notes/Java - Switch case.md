# Introduction
Switch / case is used to specify what to do in different cases, instead of writing a lot of if / else statements:
```java
String day = "Monday";

switch(day){
	case "Monday" -> System.out.println("it is Monday")
	case "Tuesday" -> System.out.println("it is Tuesday")
	case "Wednesday" -> System.out.println("it is Wednesday")
}
```
