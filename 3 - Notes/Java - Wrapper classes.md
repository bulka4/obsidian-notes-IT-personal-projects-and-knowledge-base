# Introduction
For primitive types ([[Java - Data types - Primitive and Reference variables|link]]), there are wrapper classes that can convert primitive type into an object/reference type:

|Primitive|Wrapper class|
|---|---|
|`int`|`Integer`|
|`double`|`Double`|
|`boolean`|`Boolean`|
|`char`|`Character`|
|`long`|`Long`|

For example:
```java
Integer numberObject = 10;
```
