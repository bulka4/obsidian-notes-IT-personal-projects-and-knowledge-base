# Introduction
`@Service` tells Spring to register the class as a bean.

Other common annotations include:

|Annotation|Typical responsibility|
|---|---|
|`@Controller`|MVC controller|
|`@RestController`|REST API controller|
|`@Service`|Business logic|
|`@Repository`|Data access|
|`@Component`|General-purpose Spring-managed object|

These are all ways of registering classes as Spring beans (with some additional semantics).
