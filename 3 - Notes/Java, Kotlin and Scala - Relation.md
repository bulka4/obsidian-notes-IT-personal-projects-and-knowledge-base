# Introduction
Java, Kotlin and Scala are both programming languages that run on the JVM (Java Virtual Machine) ([[Java - JVM|link]]).

That means that we can use code from one of those languages in another language, e.g.:
- Call Java classes from Kotlin.
- Call Kotlin classes from Java.
- Use Java libraries in Scala.
- Use Scala libraries in Java
