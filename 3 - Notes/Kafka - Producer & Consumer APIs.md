#BackendEngineering #Kafka 

# Introduction
Producer & Consumer APIs are APIs allowing us to write code which writes data to a Kafka topic or reads from it. They are available in Python and Java.

It is similar to Kafka Streams ([[Kafka - Kafka Streams|link]]) but Kafka Streams is higher-level with more abstractions. Using producer/consumer APIs, we have more flexibility when it comes to what do we do with the data.
