# Introduction
Representation learning is a set ML techniques where a model automatically learns a useful representation of data instead of relying on manually engineered features.

Those techniques almost always:
- Takes as an input a vector representing some features
- Outputs a new vector with new created features

So they convert one set of features into a new one, which can have a different dimension.

This new set of features is called an embedding or latent representation.
