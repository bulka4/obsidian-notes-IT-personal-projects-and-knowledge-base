#BackendEngineering 

# Introduction
The gRPC protocol uses Protocol Buffers ([[Software Engineering - Protocol Buffers|link]]) to convert data into a binary format before sending it over a network. 

It is a part of the application layer in the OSI model ([[Networking - OSI model|link]]).

Binary data uses much less memory thanks to which sending it over a network is much faster compared to data in other formats.
