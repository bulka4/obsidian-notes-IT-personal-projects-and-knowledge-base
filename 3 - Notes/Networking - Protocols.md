# Introduction
Protocols specifies how communication over a network goes. They can be applied in different layers in the OSI model ([[Networking - OSI model|link]]).

Protocols for the application layer:
- HTTP - [[Networking - Protocols - HTTP|link]] 
- gRPC - [[Networking - Protocols - gRPC|link]] 
- WebSockets - [[Networking - Protocols - WebSockets|link]] 
- SOAP - [[Networking - Protocols - SOAP (Simple Object Access Protocol)|link]] 

Protocols for the transport layer:
- TCP - [[Networking - Protocols - TCP|link]] 
- UDP - [[Networking - Protocols - UDP|link]]
