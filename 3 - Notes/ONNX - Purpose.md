#ONNX #MachineLearning 

# Introduction
The main purpose of ONNX is to standardize how machine-learning models are represented, making it easier to move models between frameworks and run them with different inference engines.

So we can train models using different frameworks (e.g. PyTorch, TensorFlow, etc.), save them all in the ONNX format and run them using different inference engines.
