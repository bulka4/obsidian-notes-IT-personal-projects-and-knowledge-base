# Introduction
Typical optimization areas:
- **Algorithm improvements**
    - Replace inefficient algorithms.
    - Example: changing a search from `O(n)` to `O(log n)`.
- **Data structures**
    - Choose better structures.
    - Example: using a `set` instead of a `list` for fast lookups.
- **Reducing unnecessary work**
    - Avoid repeated calculations.
    - Cache expensive results.
- **Memory optimization**
    - Reduce memory usage.
    - Use generators ([[Python - Generators|link]]) instead of large lists.
- **Parallelism**
    - Use multiprocessing ([[Python - Multiprocessing|link]]), multithreading, or distributed computing.
- **Database optimization**
    - Add indexes, optimize queries, reduce unnecessary queries.
- **Code-level optimization**
    - Improve slow functions, reduce I/O, optimize loops.
