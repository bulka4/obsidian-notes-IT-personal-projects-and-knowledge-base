# Introduction
These ML models extract from sentences:
- keywords
- phrases
- entities

Examples:
- “Spark partitioning”
- “distributed computing”
- “executor memory”

Techniques:
- RAKE (classic)
- TextRank (graph-based)
- transformer-based keyphrase models

Then we search using only these keyphrases.
