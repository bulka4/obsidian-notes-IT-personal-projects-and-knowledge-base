# Introduction
After retrieval, we usually get top 20–100 documents. But they are not perfectly ordered according to how relevant they are.

Reranking uses a ML model to assign relevance scores to the retrieved documents which can be used to order them.

It is a different model than the one used to create embeddings. This one is trained specifically for relevance ranking.
