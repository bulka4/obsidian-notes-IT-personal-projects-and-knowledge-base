# Introduction
Find sentences with a similar vector embeddings (similar meaning). Similarity between vector embeddings is calculated using e.g. cosine similarity.

Strengths:
- understands meaning
- handles paraphrases
- good for RAG
- Works well when relevant documents doesn't share any keywords

Weaknesses:
- weaker on exact keyword matching
- can retrieve “semantically similar but irrelevant” docs
