# Introduction
Retrieval strategies in a RAG system are the different ways you search and rank documents before sending them to the LLM:
- BM25 (keyword search) - [[RAG - Retrieval strategies - BM25 (keyword search)|link]] 
- Vector search (semantic search) - [[RAG - Retrieval strategies - Vector search (semantic search)|link]] 
- Hybrid search - Combination of BM25 and vector search
- Reranking - [[RAG - Retrieval strategies - Reranking|link]] 
- Keyphrase extraction models (ML-based “important words” detection) - [[RAG - Retrieval strategies - Keyphrase extraction models|link]] 
- Sparse neural models (modern ML version of keyword matching) - [[RAG - Retrieval strategies - Sparse neural models|link]]
