# Introduction
Chunking is the process of splitting a large document into smaller pieces (chunks) before generating embeddings and storing them in a vector database.

It is useful because when we generate an embedding for an entire, big document, this embedding might become too general, it will not capture details of different document sections. If we split the document into smaller pieces (chunks), then each chunk is about different details which might be matching the query describing what we are looking for.
