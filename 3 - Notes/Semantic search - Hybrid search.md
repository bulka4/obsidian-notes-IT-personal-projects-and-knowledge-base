# Introduction
Hybrid search combines keyword-based search and semantic vector search to get better retrieval quality.

Two main approaches:
1. Keyword search (sparse retrieval)
    - Uses exact words/tokens.
    - Example algorithms: **BM25**, inverted indexes.
    - Good for:
        - names
        - IDs
        - technical terms
        - exact matches
2. Vector search (dense retrieval)
    - Uses embeddings and similarity.
    - Good for:
        - synonyms
        - similar meanings
        - natural language queries
