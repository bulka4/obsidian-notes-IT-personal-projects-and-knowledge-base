# Introduction
The Arrange-Act-Assert (AAA) pattern is a common structure for writing tests. It divides a test into three clear steps:
# Arrange
Prepare everything needed for the test, for example:
- create test data
- initialize objects
- configure mocks
- set up dependencies
# Act
Execute the behavior we want to test.
# Assert
Check that the result is what we expect.
