# Introduction
Test reports are the outputs generated after running tests that summarize what passed, what failed, and useful details about failures.

The question:
> "What happened when we ran the tests?"

A test report usually contains:
- number of tests executed
- passed/failed/skipped tests
- failure details
- error messages
- execution time
- logs or screenshots (for some tests)
- code coverage (sometimes)
