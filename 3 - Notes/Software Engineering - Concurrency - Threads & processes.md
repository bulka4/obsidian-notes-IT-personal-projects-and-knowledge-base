# Introduction
Threads ([[Software Engineering - Threads|link]]) and processes are one way to implement concurrency. While one thread / process is waiting for something and is idle, another thread / process can process on another task.

Threads can provide:
- Concurrency - One thread / process waits, another works.
- Parallelism (if multiple CPU cores exist) - Multiple threads / processes may run simultaneously on different cores.
