# Introduction
Event replay is used in:
- Event sourcing ([[Software Engineering - Architecture patterns - Event sourcing|link]]) - It is used to rebuild state from stored events
- Event-driven architecture (EDA - [[Backend Engineering - Event-driven architecture (EDA)|link]]) - It is used to reprocesses events, recover consumers, build new projections, debug, etc.
