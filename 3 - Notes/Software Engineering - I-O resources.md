# Introduction
I/O resources are external resources that a program communicates with through I/O operations. It is something outside the program's memory that the program reads from or writes to.

Examples:
- **Network sockets** → send/receive data over a network
- **Files** → read/write data on storage
- **Databases** - read/write to a database
- **Pipes** → communicate between processes
- **Devices** → keyboard, sensors, hardware devices

In operating systems (especially Linux), these are often represented as file descriptors.
