# Introduction
Linting is a practice of checking code against a set of rules without executing it. 

We don't check how executing code behaves like in testing ([[Software Engineering - Testing|link]]) but we only check how code looks like, its structure.

As a part of linting, we can check style, practices followed and potential bugs, for example:
- unused variables
- missing imports
- lines too long

We can use for that tools such as:
- flake8 ([[_flake8|link]])
- Black ([[_Black|link]])
