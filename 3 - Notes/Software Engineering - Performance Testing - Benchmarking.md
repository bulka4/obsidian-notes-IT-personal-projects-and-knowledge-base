# Introduction
**Benchmarking** is measuring the performance of a system, component, or algorithm under controlled conditions and comparing the results.

The goal:
> "How fast/efficient is this compared to another solution or a previous version?"

Benchmarking usually focuses on specific metrics:
- execution time
- throughput
- memory usage
- CPU usage
- disk/network performance
