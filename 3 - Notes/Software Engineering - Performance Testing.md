# Introduction
**Performance testing** is testing how a system behaves under different workloads, focusing on **speed, scalability, stability, and resource usage**.

The main question:
> "Can the system handle the expected workload while meeting performance requirements?"

Tools:
- JMH (Java)
- Google Benchmark (C++)
- k6
- JMeter
