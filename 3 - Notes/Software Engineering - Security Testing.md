# Introduction
**Security testing** checks whether a system is protected against **unauthorized access, attacks, and data breaches**.

The question:

> "Can someone misuse or compromise the system?"

It tests things like:
- **Authentication** — can only valid users log in?
- **Authorization** — can users access only what they should?
- **Data protection** — is sensitive data protected?
- **Input validation** — can malicious input break the system?
- **Vulnerability exposure** — are there known security weaknesses?
