#SoftwareEngineering 

# Introduction
Software architecture design can be broken into four dimensions:
- **Domain-Driven Design (DDD) / Business Modeling** - focuses on the business problem
- **Application Design (Use Cases and Workflows)** - focuses on what the system does. It defines use cases ([[Software Engineering - Architecture concepts - Use case|link]]).
- **Software Structure and Organization** - focuses on how code is organized
- **Communication and Boundaries** - focuses on how components ([[Software Engineering - Architecture concepts - Component|link]]) / layers ([[Software Engineering - Architecture concepts - Layer|link]]) interact.
