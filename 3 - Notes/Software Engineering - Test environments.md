# Introduction
A test environment is the setup in which tests are executed. It includes everything needed for the software to run and be tested.

It can include:
- hardware or virtual machines
- operating system
- application code
- configuration
- databases
- external services
- network settings
- test data
- dependencies

Common types of environments:
```
Development environment
    ↓
Testing environment
    ↓
Staging environment
    ↓
Production environment
```
