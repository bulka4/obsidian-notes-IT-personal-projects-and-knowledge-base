#TypeScript #ProgrammingLanguages 

# Introduction
TypeScript is a programming language which adds additional functionalities to JavaScript. A TypeScript script is converted into a JavaScript language and executed.

To run it, we can either:
- Convert a TypeScript script into JavaScript and run it with a JavaScript runtime (e.g. Node.js)
- Or run a TypeScript script directly using a TypeScript runtime (e.g. `tsx`)
