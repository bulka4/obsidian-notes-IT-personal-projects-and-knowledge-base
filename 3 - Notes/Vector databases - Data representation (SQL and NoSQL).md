# Introduction
Different vector databases can use different data representations:
- Document representation (NoSQL) ([[NoSQL databases - Data representation (documents)|link]]) - Data is represented as a collection of documents where each document consists of fields. Different documents might contain different fields.
- Table representation (SQL) ([[SQL databases - Pros and cons|link]]) - Data is represented as a table with rows where every row has defined value for all the table's fields.

For example:
- NoSQL vector database - Milvus
- SQL vector database - pgvector
