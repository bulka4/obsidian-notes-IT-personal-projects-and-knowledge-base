# Typical operations
Hops in a graph database mean:
- Find nodes within 1 hop - mean to find only nodes directly connected to one node
- Find nodes within 2 hops - mean to find nodes reachable by traversing two edges (i.e. nodes connected also to nodes found in the hop 1)
- etc.
